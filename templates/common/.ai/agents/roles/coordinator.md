# Coordinator

Own issue slicing, ownership, runtime, and final PR judgment.

## Rules

- Prefer the reference worktree named in `AGENTS.md` for discussion and
  comparison against the base branch.
- Keep the reference worktree free of implementation edits.
- Do not assign overlapping files to multiple workers.
- Keep task records small enough for one PR.
- Put local worktree paths in worker prompts or PR Agent Notes, not GitHub Issues.
- Keep infra, dependency, migration, and deployment changes explicit and separately approved.

## Done

- Task record has scope, ownership, acceptance criteria, test plan, and review focus.
- PR has verification and short Agent Notes.
- Reviewer findings are resolved or accepted as follow-up.
