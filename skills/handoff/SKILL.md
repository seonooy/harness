# 작업 넘기기

작업 하나의 지금 상태를 작업 폴더의 `.handoff/<이름>.json` 한 파일에 **사진**으로 담는다. 세션을 비우고 이어 갈 때 이 파일 하나를 쓴다. 부르는 말은 `$handoff`다. 이 파일도 커밋한다.

아래 `S`는 `~/.agents/skills/handoff`다. `state.py`가 목록·검사·지우기를, `nudge.py`가 제안 훅을 맡는다.

## 인자로 고르기

| 인자 | 할 일 |
|---|---|
| 없음 | 저장 → 비우기 안내 |
| `이어 [이름]` | 이어 하기 |
| `목록` | `python3 $S/state.py list` 결과를 그대로 보여 준다 |
| `끝 [이름]` | 끝내기 |

## 저장

모든 넘기기의 첫 단계다.

1. **이름을 정한다.** `python3 $S/state.py list`에 이 작업의 파일이 있으면 그 이름을 쓴다. 없으면 작업을 나타내는 영어 소문자 kebab 이름(예: `alarm-summary`)을 새로 정한다.
2. **파일을 통째로 다시 쓴다.** 저장은 덮어쓰기다. 이어 갈 사람에게 필요한 지금 상태만 남기고, 끝나서 쓸모없어진 줄은 뺀다. 자세한 이력은 작업 로그와 git에 있으니 `refs`에 경로만 적는다.
3. **스크래치패드 파일을 옮긴다.** 임시 폴더에만 있고 이어 받을 쪽에 필요한 파일은 작업 폴더의 `tmp/handoff/<이름>/`으로 옮기고 `refs`에 새 경로를 적는다. 그 저장소가 `tmp/`를 git에서 무시하지 않으면 `.gitignore`에 넣는다. 비운 세션은 새 임시 폴더를 쓴다.
4. **검사한다.** `python3 $S/state.py check <이름>`이 `ok`를 낼 때까지 고친다.
5. **오래된 파일을 정리한다.** 목록에 `7일 넘음`이 붙은 다른 작업이 있으면 지울지 한 줄로 묻고, 지우라고 하면 `state.py done <그 이름>`.

### 칸

| 칸 | 내용 | 한도 |
|---|---|---|
| `name` | 파일 이름과 같은 kebab 이름 | 40자 |
| `title` | 사람이 읽는 작업 이름 | 80자 |
| `updated_at` | 저장 시각, ISO 8601 한국 시간(`+09:00`) | |
| `by` | 저장한 곳: `codex` | |
| `session` | (선택) 세션 ID | |
| `cwd` | 이어 받을 쪽이 시작할 폴더 | |
| `goal` | 원래 목표 한두 문장 | 400자 |
| `now` | 멈춘 지점 | 400자 |
| `next` | 바로 다음 한 단계 | 400자 |
| `rules` | 사용자가 정한 제약·선호 | 8줄 |
| `decisions` | 내린 결정과 이유 | 8줄 |
| `done` | 이번 작업에서 끝낸 것(커밋·파일) | 8줄 |
| `waiting` | 사용자 답을 기다리는 질문 | 6줄 |
| `corrections` | 틀렸다가 고친 사실 | 6줄 |
| `refs` | 경로·브랜치·URL과 그것이 무엇인지 | 10줄 |
| `running` | 백그라운드 작업과 다시 시작하는 명령(세션이 닫히면 함께 멈춘다) | 5줄 |

목록 칸은 한 줄 300자 이하, 파일 전체는 8KB 이하다. 쓸 것이 없는 목록 칸은 빼도 된다.

## 비우기 안내 (인자 없음)

저장한 뒤 다음 두 단계를 안내한다.
- Codex: `/new` 하고 `$handoff 이어 <이름>`

## 이어 하기

1. 이름이 없으면 `state.py list`를 보여 주고 고르게 한다. 파일이 하나뿐이면 그것을 쓴다.
2. 파일을 읽고 `goal`·`now`·`next`·`waiting`을 서너 줄로 사용자에게 말한다.
3. `refs` 중 `next`에 필요한 것만 읽는다. 파일과 git·작업 로그가 다르면 git과 작업 로그를 믿는다.
4. `next`가 사용자 답을 기다리는 일이면 그 질문부터 하고, 아니면 `next`부터 이어 간다. 다음에 저장할 때 `by`와 `updated_at`을 지금 쪽으로 바꾼다.

## 끝내기

남길 결론이 작업 로그에 들어갔는지, `tmp/handoff/<이름>/`에 남길 파일(그림 스크립트 등)이 없는지 확인한다. 남길 것은 제자리로 옮기고, `python3 $S/state.py done <이름>`으로 상태 파일과 그 폴더를 함께 지운다.

## 제안 훅

`nudge.py`를 `~/.codex/hooks.json`의 UserPromptSubmit에 등록하면 프롬프트마다 돈다. 컨텍스트가 창의 40%, 60%를 처음 넘을 때 한 번씩, 답 끝에 한 줄로 저장을 제안하라는 알림을 모델에게 붙인다. 저장은 사용자가 부를 때만 한다.

- 창 크기는 기록의 `model_context_window`를 쓴다.
- compact로 첫 기준 아래로 내려가면 다시 알릴 수 있다. 알린 기록은 `~/.local/state/handoff-nudge/`에 두고 7일 뒤 지운다.
