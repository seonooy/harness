이 스킬은 코드를 바꾸지 않는다. 바꾸는 파일은 `notes/briefing.md` 하나다.

사용자가 조사할 것을 말했으면 그것만 조사한다. 말하지 않았으면 README와 폴더 구조만 훑고 조사 후보 세 개를 제안한 뒤 멈춘다.

1. 질문을 한 줄로 정한다.

2. 조사한다. 프로젝트 안의 일은 파일을 읽거나 명령을 돌려 확인한다. 데이터는 일부만 보지 말고 전체를 명령으로 세고, 적은 숫자마다 돌린 명령을 남긴다. 화면이나 서버를 확인할 때는 `0.0.0.0`에 띄워 사용자가 열 주소를 준다. 외부 문서가 필요하면 공식 자료를 찾는다.

3. `notes/briefing.md`를 열어 맨 아래에 조사 기록을 더한다. 번호는 이어서 매긴다.

   ```markdown
   ## 조사 N: 제목
   - 질문:
   - 찾은 것: 사실만 적는다
   - 근거: 파일 위치, 돌린 명령, 링크
   - 모르는 것: 아직 답이 없는 것. 사람에게 물을 것은 질문으로 적는다
   ```

4. 터미널에 세 줄로 브리핑한다: 찾은 것, 아직 모르는 것, 다음 조사 후보.
