# 크레딧 (Credits)

**요약(Summary)** 절의 시각 자료 목록(의사코드, 호출 트리, 컴포넌트 트리, 파일 트리, Mermaid, diff)과 배치 지침은 [Dex Horthy](https://github.com/dexhorthy)의 [`show-me`](https://github.com/humanlayer/humanlayer) 스킬에서 왔다. 거의 한 글자도 바꾸지 않고 옮겼고, 실시간 대화 대신 diff를 대상으로 하도록 맞췄다. `pr`은 `show-me`를 스킬로서 의존하지 않는다(그 스킬은 이 저장소에 속하지 않고, 하드 의존성을 두면 독립 설치가 깨진다). 그래서 내용을 가리키지 않고 복사해 넣었다. 이 파일은 의존성이 원래 맡았을 출처 표기(attribution)다.
